# Dojo, a clickable prototype

A pixel office where I ran my own team of AI agents. I built it for myself, to be more productive.

- Everything here is mock data. It is not connected to Claude, GitHub or Jira, chat gives a canned reply, and a reload resets it.
- I used Dojo for a couple of months to build a few products, and it lifted my productivity a lot.
- It is parked now. I am building a brand-new workflow with Claude, with more complex agentic orchestration, and I may come back to refine this one.

This repo holds only the built prototype. The case study is on my portfolio.
